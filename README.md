# Gestion-Finances-Personnelles (Gestionnaire de finances personnelles)

© KIEN Le Dang Huy

Une application Python simple permettant de gérer et de suivre ses finances personnelles.

L'application permet d'ajouter des transactions, de consulter les revenus et les dépenses sur une période donnée, de calculer l'épargne nette et de visualiser l'évolution des finances à l'aide de graphiques.

## 📌 Fonctionnalités

* ➕ Ajouter une nouvelle transaction
* 📅 Enregistrer la date de chaque transaction
* 💰 Enregistrer le montant
* 📂 Classer une transaction comme :

  * `Income` — Revenu
  * `Expense` — Dépense
* 📝 Ajouter une description
* 🔎 Consulter les transactions sur une période donnée
* 📊 Calculer automatiquement :

  * le revenu total
  * les dépenses totales
  * l'épargne nette
* 📈 Afficher un graphique de l'évolution des revenus et des dépenses
* 💾 Sauvegarder automatiquement les données dans un fichier CSV

## 🛠️ Technologies utilisées

* **Python**
* **Pandas** — manipulation et analyse des données
* **Matplotlib** — création des graphiques
* **CSV** — stockage des transactions
